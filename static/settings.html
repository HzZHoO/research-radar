应用设置

设置保存在你的 GitHub 仓库。下方按钮会复制配置，并打开配置应用页面。在 GitHub 点击 Run workflow，把配置粘贴到 config_json 输入框，再运行，复制的内容已包含雷达标识，运行后只更新当前雷达的抓取方向、信源和更新时间。仅仓库所有者可以应用网页提交的配置。

在浏览器修改表单是草稿；GitHub 应用成功并完成重建后，线上设置才会生效。配置会公开保存，请不要填写密码或 API 密钥。
